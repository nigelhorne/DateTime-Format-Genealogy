  191: available.
  192:

  194:

  777: =head1 LIMITATIONS
  778: 
  779: =over 4
  780: 
  781: =item *
  782: 
  783: Dates before AD 100 are rejected because L<DateTime::Format::Natural> cannot
  784: parse them reliably (it returns today's date instead of an error).
  785: 
  786: =item *
  787: 
  788: The C<Aout> (French August with circumflex-u) entry in the month-alias table
  789: uses a non-ASCII Unicode escape (C<\x{FB}>).  The module file must be read as
  790: UTF-8; this is satisfied by the standard C<perl -Ilib> invocation but may
  791: require C<use utf8> or C<open ':encoding(UTF-8)'> in unusual environments.
  792: 
  793: =item *
  794: 
  795: Hebrew and French Republican calendar conversions require
  796: L<DateTime::Calendar::Hebrew> and L<DateTime::Calendar::FrenchRevolutionary>
  797: respectively.  These are optional and not listed as hard dependencies.  When
  798: absent, the GEDCOM escape is silently discarded and undef is returned unless
  799: the C<quiet> flag is off, in which case a carp is emitted.
  800: 
  801: =item *
  802: 
  803: L<Genealogy::Gedcom::Date> cannot parse native Hebrew or French Revolutionary
  804: month names (e.g. C<Tishri>, C<Vendemiaire>).  Only dates written in
  805: Gregorian form with the C<@#DHEBREW@> escape are converted.
  806: 
  807: =item *
  808: 
  809: The C<quiet> and C<strict> flags may be set at construction time
  810: (C<< ->new(quiet => 1) >>) and will be respected by all subsequent calls to
  811: C<parse_datetime> unless overridden on a per-call basis.  The per-call value
  812: always takes precedence.

  870: =head2 parse_datetime
  871: 
  872: Let D be the set of genealogical date strings and DT the co-domain of
  873: L<DateTime> objects.
  874: 
  875:     parse_datetime : D -> DT | bot | (DT x DT)
  876: 
  877:     YearOnly ::= { s in D | s ~ /^\d{3,4}$/ }
  878:     Approx   ::= { s in D | s ~ /^(bef|aft|abt)\s/i }
  879:     Ranges   ::= { s in D | s ~ /^bet\s.+\sand\s.+/i
  880:                            | s ~ /^from\s.+\sto\s.+/i }
  881: 
  882:     Pre:  date != bot
  883: 
  884:     Post:
  885:       date in YearOnly              => result = bot
  886:       date in Approx                => result = bot  (carp unless quiet)
  887:       date in Ranges /\ wantarray   => result in DT x DT
  888:       date in Ranges /\ !wantarray  => result = bot
  889:       date in Parseable \
  890:         (YearOnly u Approx u Ranges) => result in DT
  891:       date not in Parseable         => result = bot  (carp unless quiet)
